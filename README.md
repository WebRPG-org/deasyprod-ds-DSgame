# Последний лифт

**Эпизод 01: «Пассажир без этажа»** — короткая интерактивная история на RPG Maker MV для мобильного браузера.

Ты приходишь в себя в лифте. На ладони: «Ты живёшь на 108-м. Не верь себе после 40-го». На первом этаже идёт снег, а девочка с чемоданом просит отвезти её туда, где её ждут.

## Играть локально

Из корня проекта, с Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000` в браузере с WebGL. Игра не требует npm-пакетов, сервера базы данных, аккаунта или сборки. Для проверки на телефоне в своей локальной сети запустите `npm start` и откройте адрес компьютера с портом 8000. В облачной среде адрес зависит от доступного механизма публикации.

Проект также открывается через `Game.rpgproject` в лицензированном редакторе RPG Maker MV. Текущая браузерная сборка проверяется в Chromium; отдельная упаковка под Android/iOS и запуск в штатном NW.js редактора пока не проверены.

## Что есть в эпизоде

- Пять иллюстрированных этажей: снежный подъезд, бюро забытых вещей, сад тихих голосов, встречный лифт и квартира 108.
- Выборы с последствиями: ключ или воспоминание, энергия для сада или батарея себе, доверие спутницы.
- Ограниченный багаж, улучшение кабины и возобновляемая энергия через ручной привод. Разряженная батарея не заставляет начинать заново.
- Три финала, дневник находок и отдельное автосохранение после каждого действия.
- Портретный интерфейс 480×900, настоящие touch-кнопки, управление мышью и клавиатурой. Иллюстрации рисуются локально; внешних запросов и скачивания ресурсов во время игры нет.
- Необязательный синтезированный фон и звук прибытия. По умолчанию звук выключен.

Это первый законченный эпизод-прототип, а не полная кампания. В нём нет боевой системы, свободного хождения по картам и платных механик.

## Управление и сохранения

Касайтесь крупных кнопок. «Кабина» возвращает в безопасное место, «Этажи» открывает панель, «Дневник» показывает багаж и записи. Поездка на другой этаж стоит один заряд; осмотр текущего этажа бесплатный. В кабине можно зарядить лифт вручную и укрепить полку найденной пластиной.

На клавиатуре: Tab / Enter для кнопок, 1–3 для вариантов ответа, Escape для возврата в кабину. На телефоне используйте вертикальную ориентацию.

Прогресс хранится в `localStorage` с ключом `dsgame.last-lift.episode-1.v1`. Он привязан к браузеру и адресу игры; очистка данных сайта удалит его. Сохранения старого проекта MV не перезаписываются. Новая игра требует подтверждения. При запрете записи в хранилище появляется сообщение.

## Проверки

Node.js 18+ нужен только для тестов правил и проверки синтаксиса:

```sh
npm test
npm run check
```

Функциональные тесты браузера используют Python Playwright и установленный Chromium:

```sh
python3 -m pip install -r tests/requirements.txt
# В другом терминале запустите HTTP-сервер из корня проекта.
python3 tests/mobile_smoke.py --url http://127.0.0.1:8000
```

Сценарии проходят все три финала настоящими касаниями, проверяют автосохранение после перезагрузки, подтверждение новой игры, исчерпание энергии и ручной привод, поворот телефона, клавиатуру, повреждённое сохранение и ошибки загрузки/JavaScript. Скриншоты и отчёт по умолчанию сохраняются вне репозитория в `/tmp/last-lift-artifacts`. Путь к Chromium в тесте: `/usr/bin/chromium`; можно передать `--chromium /путь/к/браузеру` либо установить браузер командой `python3 -m playwright install chromium` и использовать `--chromium playwright`.

GitHub Actions запускает проверки правил и браузерные сценарии при push и pull request; скриншоты сохраняются как артефакт `last-lift-browser-results`.

## Структура

- `js/plugins/LastLiftStory.js` — независимые от движка правила, текст, переходы и схема сохранения. Состояние обновляется без изменения предыдущего снимка.
- `js/plugins/LastLift.js` — сцена MV, портретный интерфейс, пиксельные иллюстрации, звук, доступные HTML-кнопки поверх игрового canvas и автосохранение.
- `js/plugins.js` — активны Community_Basic, LastLiftStory и LastLift. Старые плагины NEON SLAUGHTER сохранены, но отключены.
- `tests/` — проверки сюжета и браузера.

Включайте LastLiftStory перед LastLift в менеджере плагинов. Игровая сцена запускается после стандартного Scene_Boot; исходные файлы движка не заменяются. В репозитории уже используется адаптация ядра MV для Pixi 7.4.3.
